# Context Mode Search

1. Batch related questions where possible.
2. Scope results to a source label when the user named one.
3. Use two-to-four-term queries such as `authentication middleware` or `token refresh`.
4. Return useful snippets and source identifiers without dumping the whole corpus.
5. If the index is empty, explain that indexing must run first.
